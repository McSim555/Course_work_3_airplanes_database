# Проект 3. Поиск информации о самолётах в воздушном пространстве выбранных стран с подключением БД

## Описание: Получение по API информации о самолётах в воздушном пространстве выбранных стран. Создание БД и ее заполнение полученной информацией о самолётах. Создание класса для работы с БД..

## Установка:
- Клонируйте репозиторий
```git clone https://github.com/McSim555/Course_work_3_airplanes_database``
- Откройте проект bank_application в PyCharm версии >= 3.14

## Использование:

1. Откройте ветку feature
``` git branch feature ```

2. Откройте файл main.py и запустите. Вводите на терминале названия выбранных стран на английском языке через запятую и пробел.
   Результаты работы методов для класса работы с БД будут выводиться в консоль.

3. Краткое описание основных модулей.
   - модуль ```utils.py``` содержит функции для получения информации о странах от пользователя, получения координат выбранных страна и информации о самолётах в их воздушных пространствах
   - модуль ```database.py``` создаёт БД и сохраняет информацию о странах и самолётах в нее
   - модуль ```db_manager.py``` содержит класс и методы для работы с БД

4. Внешние источники информации
   Для получения географических координат стран использовался ресурс https://nominatim.openstreetmap.org/
   Для получения информации о самолётах использовался https://opensky-network.org/

5. Тестирование
В ходе проекта для тестирования использовался фреймворк тестирования pytest
Для их запуска выполните команду: ```pytest```
