# Проект 2. Получение информации о самолётах в воздушном пространстве стран и ёё обработка

## Описание: Создание классов и методов для получения по API информации о самолётах в воздушном пространстве выбранной страны. Создание классов для обработки полученной информации и ее записи в файл. модуль взаимодействия с пользователем.


## Установка:

- Клонируйте репозиторий
```git clone https://github.com/McSim555/Course_work_2_airplanes_tracker``
- Откройте проект bank_application в PyCharm версии >= 3.14

## Использование:

1. Откройте ветку feature
``` git branch feature ```

2. Откройте файл main.py и запустите. Вводите необходимую информацию на терминале.
   Результаты работы функция будут выводится в консоль.

3. Краткое описание основных модулей.
   - модуль ```airplane_data.py``` содержит класс Самолёт с основными атрибутами и описывает методы для сравнения объектов по высоте и скорости
   - модуль ```api_country.py``` описывает класс для получения по API координат выбранной стране
   - модуль ```api_airplane.py``` содержит класс и методы для получения информации о самолётах в выбранной стране, создания списка самолётов с ограниченным набором параметров, получения списка самолётов из объекта
   - модуль ```json_file_work_airplane``` имеет класс для работы с файлом в формате JSON для одного самолёта. Методы позволяют добавить, получить и удалить информацию о самолёте в файле
   - модуль ```json_file_work_airplanes``` содержит класс для работы с файлом для набора самолётов. Можно найти, добавить или удалить информацию о самолётах в файле
   - модуль ```user_interaction.py``` описывает структуру взаимодействия с пользователем

4. Сохранение в файл
   В данном проекте рабочие файлы формата JSON сохранялись в папку ```data``` в корне проекта

5. Внешние источники информации
   Для получения географических координат стран использовался ресурс https://nominatim.openstreetmap.org/
   Для получения информации о самолётах использовался https://opensky-network.org/

6. Тестирование
В ходе проекта для тестирования использовался фреймворк тестирования pytest
Для их запуска выполните команду: ```pytest```
